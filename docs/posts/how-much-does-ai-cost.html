How much does AI Cost?

Providers charge according to the tokens processed:

  • Input tokens: the tokens sent to the model.
  • Output tokens: the tokens generated by the model.
  • Cached tokens: previously processed input tokens reused at a lower price.

Without caching, the cost of a single request is:

Cost = X times I + Y times O

The model's maximum context length is not necessarily the number of tokens billed: you pay for the tokens actually processed.

With prompt caching, previously processed input can be reused for a limited time:

  • Cache write: Storing input tokens for potential reuse. This may cost more than regular input processing.
  • Cache read (cache hit): Reusing cached tokens at a reduced price.

A cache read works only while the cached content is still valid. The exact lifetime and prices depend on the provider and model.

Example

Suppose 15 requests process 30,000 input tokens and generate 1,500 output tokens each. Assume input costs 2 dollars per MT, output costs 10 dollars, cache writes cost 2.50 dollars, and cache reads cost 0.20 dollars.

With caching, the first request costs:

0.03 times 2.5 + 0.0015 times 10 = 0.09 dollars

The remaining 14 requests cost:

14 times (0.03 times 0.2 + 0.0015 times 10) = 0.294 dollars

The total is therefore 0.384 dollars. Without caching, the 15 requests cost:

15 times (0.03 times 2 + 0.0015 times 10) = 1.125 dollars

Caching saves 0.741 dollars, or approximately 65.9%. In short, repeatedly sending the same context can make prompt caching significantly cheaper.
