How Much Does AI Cost?

I've just read an article about how AI providers charge for usage. Here's my understanding.

How it works

When you send a prompt to an AI model, the provider charges you based on the number of tokens processed.

There are three main costs to consider:

  • Input tokens: The text sent to the model.
  • Output tokens: The text generated by the model.
  • Cached tokens: Previously processed input tokens that can be reused at a reduced cost.

Pricing is usually expressed in dollars per million tokens (MT).

Let's define:

  • (I): input price per million tokens.
  • (O): output price per million tokens.
  • (X): number of input tokens, measured in millions.
  • (Y): number of output tokens, measured in millions.

For a single request without caching, the cost is:

$$ C = X \cdot I + Y \cdot O $$

Notice that the model's maximum context length is not necessarily the number of tokens billed. You pay for the tokens actually processed, according to the provider's pricing rules.

What happens when you send a second prompt?

Does the model process the entire context again, charging you the full input price?

Not necessarily! Some providers offer prompt caching, which allows previously processed input tokens to be reused at a lower price.

There are two important operations:

  • Cache write: Storing input tokens for potential reuse. This may cost more than standard input processing.
  • Cache read (cache hit): Reusing cached tokens at a reduced price.

A cache read is possible only if the relevant content has already been cached and the cache is still valid.

Think of caching as temporarily storing a reusable portion of your prompt. The provider keeps that content available for a limited time, potentially reducing the cost of subsequent requests.

For example, a provider might offer a cache with a five-minute lifetime. The exact duration, pricing, and eligibility rules depend on the provider and model.

Example

Let's estimate the cost of making 15 requests, assuming each request processes the same 30,000 input tokens and generates an average of 1,500 output tokens.

Suppose the provider charges:

Parameter Value
Input price (I = \$2/\text{MT})
Output price (O = \$10/\text{MT})
Input length (X = 30{,}000/10^6 = 0.03\,\text{MT})
Average output length (Y = 1{,}500/10^6 = 0.0015\,\text{MT})
Cache write price (W = \$2.50/\text{MT})
Cache read price (R = \$0.20/\text{MT})

Here, MT means one million tokens.

With caching

Assume the first request writes the input to the cache and the remaining 14 requests successfully reuse all 30,000 cached input tokens.

First request:

The input is written to the cache, so we use the cache write price:

$$ \begin{aligned} C_1 &= X \cdot W + Y \cdot O \ &= 0.03 \times 2.50 + 0.0015 \times 10 \ &= 0.075 + 0.015 \ &= \$0.09 \end{aligned} $$

Remaining 14 requests:

Each request reads the cached input and generates a new output:

$$ \begin{aligned} C_{\text{rest}} &= 14 \cdot (X \cdot R + Y \cdot O) \ &= 14 \cdot (0.03 \times 0.20 + 0.0015 \times 10) \ &= 14 \cdot (0.006 + 0.015) \ &= 14 \times 0.021 \ &= \$0.294 \end{aligned} $$

Total cost with caching:

$$ \begin{aligned} C_{\text{cached}} &= C_1 + C_{\text{rest}} \ &= 0.09 + 0.294 \ &= \boxed{\$0.384} \end{aligned} $$

Without caching

Now suppose every request processes the input at the standard input price.

Each request costs:

$$ \begin{aligned} C_{\text{request}} &= X \cdot I + Y \cdot O \ &= 0.03 \times 2 + 0.0015 \times 10 \ &= 0.06 + 0.015 \ &= \$0.075 \end{aligned} $$

For all 15 requests:

$$ \begin{aligned} C_{\text{uncached}} &= 15 \cdot C_{\text{request}} \ &= 15 \times 0.075 \ &= \boxed{\$1.125} \end{aligned} $$

How much do we save?

The absolute savings are:

$$ \begin{aligned} S &= C_{\text{uncached}} - C_{\text{cached}} \ &= 1.125 - 0.384 \ &= \$0.741 \end{aligned} $$

The percentage reduction is:

$$ \begin{aligned} S_{\%} &= \frac{C_{\text{uncached}} - C_{\text{cached}}} {C_{\text{uncached}}} \times 100 \ &= \frac{0.741}{1.125} \times 100 \ &\approx \boxed{65.9\%} \end{aligned} $$

In this example, prompt caching reduces the total cost by approximately 65.9%.

A few things to keep in mind

This example simplifies how caching works. In practice:

  • Caches expire. If the cache expires before the next request, the input may need to be processed and cached again.
  • Cache writes may cost more. Some providers charge a premium for writing cached tokens.
  • Not everything must be cached. A request may contain both cached and uncached input tokens.
  • Output costs remain. Caching input does not eliminate the cost of generating new output tokens.
  • Context length is not usage. A model's maximum context length is a limit, not a fixed amount of input billed on every request.

Actual costs depend on the provider's pricing, cache lifetime, eligible tokens, and caching rules.

The key takeaway is simple: if your application repeatedly sends the same context, prompt caching can significantly reduce input costs.
